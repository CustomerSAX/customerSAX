# customerSAX — Human Agent vs AI Agent Battle Card

## Positioning statement
**customerSAX is not an AI-agent platform replacing the helpdesk. It is a customer service platform that runs a mixed human + AI service workforce.**

The buyer does not need to choose between people and AI. The operating question is: **which work should go to which worker, under which policy and with which handoff?**

| Dimension | Human service agent | AI service agent | customerSAX role |
|---|---|---|---|
| Availability | Scheduled / capacity constrained | 24/7 / elastic | Route based on urgency and availability |
| Best at | Empathy, ambiguity, negotiation, exceptions | Repetition, lookup, summarization, policy-bound action | Match intent and risk to worker |
| Context gathering | Can investigate deeply but time is expensive | Can gather cross-system context quickly | Give both the same customer + commerce context |
| Authority | Can use judgment and discretion | Must stay within explicit guardrails | Policy, role, value and approval limits |
| High-volume work | Expensive to scale | Efficient to scale | AI-led where the path is proven |
| High-risk work | Strong fit | Assist, do not own by default | Human-led with AI preparation |
| Handoff | Receives context from prior work | Must escalate cleanly | Preserve conversation, evidence, reasoning and next action |
| Quality | Coaching, QA, calibration | Evaluation, policy adherence, failure monitoring | One QA model across both workforces |

## Three service modes
### 1. AI-led
Use for repeatable, policy-safe journeys such as order status, simple returns, standard appointment changes, basic billing questions and known product questions.

### 2. Human + AI
AI gathers context, summarizes history, recommends a path, drafts the response or prepares an action. The human adapts, approves and owns the customer relationship.

### 3. Human-led
Use for complaints, vulnerable customers, fraud/risk, policy exceptions, negotiation, high-value recovery, emotionally sensitive situations and novel edge cases.

## Buyer transition story
1. **Unified human service** — channels, queues, cases, knowledge, customer + order context.
2. **AI-assisted service** — summaries, drafts, intent, knowledge, next-best action.
3. **AI coworkers** — investigation and bounded task execution with approval.
4. **Autonomous resolution** — proven low-risk intents with policy, audit and immediate handoff.

## Competitive message
Do not lead with “our AI agent is better than your human agents.” Lead with:

> **Your service team already has humans, queues, customers, SLAs, policies and systems. customerSAX makes that operating model AI-native — without asking you to throw it away first.**
