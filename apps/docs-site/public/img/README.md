# Documentation images

Drop screenshots and exported diagrams here and reference them from MDX with a
root-relative path, e.g.:

```md
![Service topology](/img/architecture/topology.png)
```

Suggested structure:

- `architecture/` — topology, sequence and flow diagrams, annotated console
  screenshots.
- `guides/` — step screenshots for task walkthroughs.
