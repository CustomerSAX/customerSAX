## Responsibilities

- **Tenancy** — clients and projects that scope everything else in the platform.
- **Roles** — the role definitions that back the ACL flags the assistant and the
  studio enforce.
- **AI settings** — per-tenant configuration for the assistant.
- **Audit** — audit records for administrative actions.

## Federation

admin is a federated subgraph reached through the BFF. Its data underpins the
identity headers the gateway stamps onto every subgraph request
(`x-csa-client-id`, `x-csa-project-key`, `x-csa-user-role`).
